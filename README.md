# وب‌سایت و پنل مدیریت عمارت مسعودیه

سایت پویا با پنل فارسی برای ساخت صفحه، ویرایش متن و آپلود عکس.

## اجرا با داکر

```bash
docker compose -p masoudieh up -d --build
```

- سایت: `http://IP-سرور:8060`
- پنل: `http://IP-سرور:8060/admin`

ورود پیش‌فرض:

- نام کاربری: `admin`
- رمز: `Masoudieh@1405`

رمز را بعد از ورود از «تنظیمات سایت» عوض کنید.

عکس‌ها و متن‌های ذخیره‌شده در پوشه `data` می‌مانند. این پوشه را هم همراه پروژه روی سرور نگه دارید.

## کارهایی که در پنل می‌توانید بکنید

- ساخت صفحه جدید و گذاشتن آن در سربرگ
- عوض کردن عنوان، متن، عکس بزرگ و ترتیب منو
- چیدن صفحه با بلوک: متن+عکس، متن آزاد، کارت، گالری، خط زمان، اخبار
- آپلود و انتخاب عکس از کتابخانه رسانه
- تنظیم نام سایت، نشانی، تلفن و پاورقی
- دیدن پیام‌های فرم تماس

## توقف

```bash
docker compose -p masoudieh down
```
