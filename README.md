# وب‌سایت و پنل مدیریت عمارت مسعودیه

سایت پویا با پنل فارسی برای ساخت صفحه، ویرایش متن و آپلود عکس.

## اجرا با داکر

```bash
docker compose -p masoudieh up -d --build
```

- سایت: `http://IP-سرور:8060`
- پنل: `http://IP-سرور:8060/admin`

ورود پیش‌فرض:

- نام کاربری: `admin`
- رمز: `Masoudieh@1405`

رمز را بعد از ورود از «تنظیمات سایت» عوض کنید.

عکس‌ها و متن‌های ذخیره‌شده در پوشه `data` می‌مانند. این پوشه را هم همراه پروژه روی سرور نگه دارید.

اگر به‌خاطر نام فارسی پوشه خطا گرفتید، همان دستور با `-p masoudieh` را بزنید.

## کارهایی که در پنل می‌توانید بکنید

- ساخت صفحه جدید و گذاشتن آن در سربرگ
- عوض کردن عنوان، متن، عکس بزرگ، توضیح سئو و ترتیب منو
- پیش‌نمایش صفحه قبل از ذخیره
- چیدن صفحه با بلوک: متن+عکس، متن آزاد (ویرایشگر)، کارت، گالری، خط زمان
- اخبار جدا (تاریخ، دسته، پیش‌نویس / انتشار)
- نقشه فضاهای حیاط و تور بازدید
- آپلود عکس با فشرده‌سازی WebP و چند اندازه
- برش و جایگزینی عکس
- کاربران پنل با نقش مدیر / ویرایشگر
- تنظیم ساعات بازدید، نشانی، تلفن و پاورقی
- دیدن پیام‌های فرم تماس

## توقف

```bash
docker compose -p masoudieh down
```
